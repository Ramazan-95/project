AppleStore — Интернет-магазин техники Apple

AppleStore — это современный адаптивный интернет-магазин техники Apple, созданный с использованием HTML, CSS и JavaScript. Проект выполнен в минималистичном стиле с акцентом на удобство использования, привлекательный дизайн и простую навигацию.

Возможности сайта
Главная страница со стильным приветственным баннером.
Каталог товаров: iPhone, MacBook, iPad и Apple Watch.
Корзина покупок с возможностью добавления и удаления товаров.
Автоматический подсчёт общей стоимости заказа.
Демонстрационная функция оформления заказа.
Адаптивный дизайн для компьютеров, планшетов и смартфонов.
Плавные анимации и интерактивные элементы.

Установка и запуск
Скачайте или клонируйте репозиторий.
Откройте папку проекта.
Запустите файл index.html в браузере.
Пользуйтесь интернет-магазином.
Дизайн

Тёмная цветовая гамма.

Стильные карточки товаров.

Плавные анимации и эффекты наведения.

Проект является демонстрационным интернет-магазином. Функции оплаты и реального оформления заказов пока не реализованы.
